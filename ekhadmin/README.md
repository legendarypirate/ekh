# ЭнхЭх · Эмчийн Web Admin

Next.js port of `ekh_admin.html`. Clinic, district, and Super Admin screens, demo data, and local persistence match the original HTML app.

## Run

```bash
cd ekhadmin
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
